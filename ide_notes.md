# Git в VS Code

## Что удобно в VS Code

1. В панели Source Control сразу видно измененные файлы и можно быстро открыть diff.
2. Удобно писать сообщение коммита и проверять staged/unstaged изменения перед фиксацией.
3. Расширение GitLens помогает понять историю строк и быстрее ориентироваться в изменениях.

## Что удобнее делать в терминале

Сложные операции с историей, например `rebase`, `cherry-pick` и просмотр `git log --graph`, удобнее выполнять в терминале, потому что команды явно показывают, что происходит.
