# Сравнение Git и SVN

## Почему в Git ветвление дешевое, а в SVN дорогое?

В Git ветка - это легкая ссылка на коммит, поэтому ее создание происходит почти мгновенно и не требует копирования всего проекта. В SVN ветвление исторически связано с копированием директорий внутри централизованного репозитория, поэтому операция тяжелее и сильнее зависит от сервера.

## Можно ли в SVN сделать коммит без интернета?

Нет, полноценный коммит в SVN требует подключения к центральному серверу. Локально можно менять файлы, но зафиксировать изменения в истории без доступа к серверу нельзя.

## Когда SVN может быть предпочтительнее Git?

SVN может быть удобен в legacy-проектах, где уже настроена инфраструктура, права доступа и процессы вокруг централизованного репозитория. Еще он может подойти командам, которым нужна простая модель с одним главным сервером и без распределенной истории у каждого разработчика.
